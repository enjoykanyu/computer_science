# 基础类型变量

### 整型和布尔
```cpp
#include <iostream>

int main () {
  int i = 9;
  // read value into i        
  // print value of i
  bool b1 = true;
  bool b2 = false;
  std::cout << i << '\n'; 
  std::cout << b1 << '\n'; 
  std::cout << b2 << '\n'; 
}
```

### char字符

```cpp
#include <iostream>

int main () {
  char c = 'A';  // character literal
  char a = 65;  
  std::cout << c << '\n'; 
  std::cout << a << '\n'; 
}
```
