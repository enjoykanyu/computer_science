# 集合
## 一、什么是集合？

**定义1**：集合是**不同对象**的**无序**聚集。对象叫元素（element）或成员（member）。

> 三个关键词：**不同**（不重复）、**无序**（{a,b} = {b,a}）、**聚集**

### 两种表示法

| 方法 | 写法 | 例子 |
|------|------|------|
| 花名册方法（列举法） | 把元素列在花括号里 | V = {a, e, i, o, u} |
| 集合构造器（描述法） | {x \| x 满足性质 P} | O = {x \| x 是小于10的正奇数} |

### 必记的常见集合符号

| 符号 | 含义 | 符号 | 含义 |
|------|------|------|------|
| **N** | 自然数 {0,1,2,3,…} | **R** | 实数 |
| **Z** | 整数 {…,-2,-1,0,1,2,…} | **R⁺** | 正实数 |
| **Z⁺** | 正整数 {1,2,3,…} | **C** | 复数 |
| **Q** | 有理数 | **∅** 或 {} | 空集 |

### 区间记号

```
[a, b] = {x | a ≤ x ≤ b}  闭区间
(a, b) = {x | a < x < b}  开区间
[a, b) = {x | a ≤ x < b}  半开半闭
(a, b] = {x | a < x ≤ b}  半开半闭
```

**重要概念**：集合可以包含其他集合作为元素，如 `{N, Z, Q, R}` 包含4个元素，每个都是集合。

## 二、子集与相等

**定义2 — 集合相等**：A = B 当且仅当 ∀x(x∈A ↔ x∈B)。即两个集合元素完全相同。

**定义3 — 子集**：A ⊆ B 当且仅当 ∀x(x∈A → x∈B)。A 的每个元素都在 B 中。

> **判断口诀**：A⊆B → "A 的元素全在 B 里"；A=B → "互相包含"

**真子集**：A ⊂ B 表示 A⊆B 且 A≠B（B 比 A 多至少一个元素）。

**定理1**：∅ ⊆ S（空集是任何集合的子集）

> 证明用的是空证明：x∈∅ 恒为假，所以 x∈∅ → x∈S 恒为真。

**证明两个集合相等的方法**：分别证明 A⊆B 和 B⊆A。

### 空集 vs 含空集的集合（最容易混淆）

| 集合 | 有几个元素？ | 说明 |
|------|-----------|------|
| ∅ 或 {} | 0 个 | 空集本身 |
| {∅} | 1 个 | 包含空集作为元素的集合 |
| {∅, {∅}} | 2 个 | 包含空集和 {∅} |

## 三、集合的大小

**定义4 — 基数**：有限集 S 中不同元素的个数记为 |S|。

**定义5 — 无限集**：不是有限集的集合。

| 例子 | 基数 |
|------|------|
| \|{a, b, c}\| | 3 |
| \|∅\| | 0 |
| \|{∅}\| | 1（注意：空集是它的一个元素） |
| \|N\| | 无限 |

---

## 四、幂集

**定义6 — 幂集**：S 的**所有子集**组成的集合，记作 P(S)。

> 幂集 = "把 S 的所有子集打包成一个新集合"

**核心公式**：若 |S| = n，则 |P(S)| = **2ⁿ**

**例**：S = {0, 1, 2}

```
P(S) = {∅, {0}, {1}, {2}, {0,1}, {0,2}, {1,2}, {0,1,2}}
|P(S)| = 8 = 2³
```

**注意**：∅ 和 S 本身总是幂集的成员。

**易错题**：

- P(∅) = {∅}（1个元素，不是0个！）
- P({∅}) = {∅, {∅}}（2个元素）

## 五、笛卡儿积

**定义7 — 有序 n 元组**：(a₁, a₂, …, aₙ)，顺序重要！(a,b) ≠ (b,a) 除非 a=b。

**定义8 — 笛卡儿积**：A × B = {(a, b) | a∈A 且 b∈B}

> 笛卡儿积 = "A 中每个元素和 B 中每个元素配对"

**例**：A = {1, 2}，B = {a, b, c}

```
A × B = {(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)}
B × A = {(a,1), (a,2), (b,1), (b,2), (c,1), (c,2)}
```

**核心性质**：A×B ≠ B×A（除非 A=B 或有一个为空集）

**定义9 — 多集合笛卡儿积**：A₁×A₂×…×Aₙ = {(a₁,…,aₙ) | aᵢ∈Aᵢ}

**Aⁿ 记号**：A² = A×A，A³ = A×A×A，以此类推。

**关系**：A×B 的任意子集 R 称为从 A 到 B 的**关系**。这是第9章的前置概念。

## 六、带量词的集合符号

| 简写 | 等价于 | 含义 |
|------|--------|------|
| ∀x∈S (P(x)) | ∀x (x∈S → P(x)) | S 中所有元素满足 P |
| ∃x∈S (P(x)) | ∃x (x∈S ∧ P(x)) | S 中存在元素满足 P |

---

## 七、真值集

**定义**：谓词 P(x) 在论域 D 上的真值集 = {x∈D | P(x) 为真}

**核心结论**：

- ∀xP(x) 为真 ↔ 真值集 = 整个论域
- ∃xP(x) 为真 ↔ 真值集 ≠ ∅

## 八、核心练习

### 基础题

**练习1**：列出集合成员

- a) {x | x 是使得 x²=1 的实数} → **{-1, 1}**
- c) {x | x 是整数的平方且 x<100} → **{0, 1, 4, 9, 16, 25, 36, 49, 64, 81}**

**练习2**：用集合构造器描述

- a) {0, 3, 6, 9, 12} → **{x | x = 3n, n∈N 且 n≤4}** 或 **{x∈N | x 是 3 的倍数且 x≤12}**

**练习5**：判断子集关系

- a) 从纽约到新德里的**不经停航班** ⊆ 从纽约到新德里的**所有航班** → 第一个是第二个的子集
- c) 飞鼠 ⊆ 会飞行的生物 → 第一个是第二个的子集

**练习7**：判断是否相等

- a) {1,3,3,3,5,5,5,5,5} = {5,3,1} → **相等**（集合不重复、无序）
- b) {{1}} ≠ {1, {1}} → **不相等**（前者只有一个元素 {1}，后者有两个元素 1 和 {1}）
- c) ∅ ≠ {∅} → **不相等**（前者0个元素，后者1个元素）

**练习8**：A={2,4,6}, B={2,6}, C={4,6}, D={4,6,8}

- B⊆A, C⊆A, C⊆D

**练习9**：2 是元素吗？

- a) {x∈R | x 是大于1的整数} → **是**（2>1 且是整数）
- b) {x∈R | x 是整数的平方} → **不是**（2 不是完全平方数）
- c) {2, {2}} → **是**（2 直接是元素）
- d) {{2}, {{2}}} → **不是**（元素是 {2} 和 {{2}}，不是 2）
- e) {{2}, {2,{2}}} → **不是**
- f) {{{2}}} → **不是**

**练习10**：{2} 是元素吗？（对练习9的每个集合）

- a) **不是**；b) **不是**；c) **是**；d) **是**；e) **是**；f) **不是**

**练习11**：判断真假

- a) ∅∈∅ → **假**（空集没有元素）
- b) ∅⊆{∅} → **真**（空集是任何集合的子集）
- c) {∅}⊆∅ → **假**（{∅} 有元素 ∅，但 ∅ 没有元素）
- d) ∅⊆{∅} → **真**
- e) {∅}∈{∅} → **假**（{∅} 不是自身的元素，它是自身的子集）
- f) {∅}⊆{∅} → **真**（任何集合是自身的子集）
- g) {∅} = {∅} → **真**

**练习12**：

- a) ∅ ∈ {∅} → **真**
- b) ∅ ∈ {∅, {∅}} → **真**（∅ 是第一个元素）
- c) {∅} ⊆ {∅} → **真**
- d) {∅} ⊆ {{∅}} → **假**（∅ 不是 {{∅}} 的元素）
- e) {∅} ⊆ {∅, {∅}} → **真**（{∅} 是第二个元素）
- f) {{∅}} ⊆ {∅, {∅}} → **真**
- g) {{∅}} ⊆ {{∅}, {∅}} → **真**（注意 {{∅}, {∅}} = {{∅}}，因为集合不重复）

**练习13**：

- a) x ∈ {x} → **真**
- b) {x} ⊆ {x} → **真**
- c) {x} ∈ {x} → **假**（x 是元素，{x} 不是）
- d) {x} ∈ {{x}} → **真**
- e) ∅ ⊆ {x} → **真**
- f) ∅ ∈ {x} → **假**

## 最容易踩的坑

1. **∈ 和 ⊆ 搞混** → `{a} ∈ {{a}}` 是真，但 `{a} ⊆ {{a}}` 是假
2. **∅ 和 {∅} 搞混** → ∅ 有 0 个元素，{∅} 有 1 个元素
3. **A×B ≠ B×A** → 笛卡儿积不满足交换律
