# 计算机编码
- ASCII 编码
  ASCII 编码‌（American Standard Code for Information Interchange）是基于拉丁字母的电脑编码系统，‌使用 7 位二进制数表示 128 个字符‌。它主要用于显示现代英语和其他西欧语言，是现今最通用的单字节编码系统

- Base 编码
  Base 编码是一组将二进制数据转换为文本字符串的编码方案，‌主要用于在只支持文本的系统中安全传输或存储二进制数据‌。它不是加密算法，数据可被还原，无保密性。‌‌ 
  
Base64‌：最常用，使用 64 个字符（A-Z, a-z, 0-9, +, /），编码后体积增大约 33%。 
Base32‌：使用 32 个字符（A-Z, 2-7），不区分大小写，适合文件名等场景。 
Base16‌：即十六进制（Hex），使用 0-9 和 A-F，每字节转为 2 字符。 
Base58‌：去除易混淆字符（如 0, O, I, l），常用于比特币地址

- 霍夫曼编码
霍夫曼编码是一种用于无损数据压缩的变长编码算法‌，它的核心思想是让出现频率高的字符使用较短的二进制码，出现频率低的字符使用较长的码，从而在整体上缩短数据的存储长度 
- XXencoding
一种将二进制数据转换为可打印 ASCII 字符的编码方案，常用于早期 Unix 系统和邮件传输中
  
- URL 编码
  URL 编码也叫百分号编码，主要把 URL 中的特殊字符或中文转成安全字符，确保数据传输不乱码 。它通过将字符转换为%加上两位十六进制数来表示

- Unicode 编码
Unicode 编码是国际字符编码标准，为每个字符分配唯一码点，UTF-8/UTF-16/UTF-32 是其具体编码实现格式。

核心概念区分
Unicode 标准‌：字符集规范，定义字符与码点的映射关系（如"汉"对应 U+6C49），由 Unicode 联盟制定。
UTF 编码格式‌：将 Unicode 码点转换为字节存储的具体实现方式，UTF 是"Unicode Transformation Format"缩写。‌‌

常见编码格式
UTF-8‌：1-4 字节可变长度，兼容 ASCII，互联网最常用。
ASCII 字符用 1 字节，中文字符用 3 字节，生僻字符用 4 字节。‌‌‌
UTF-16‌：2 或 4 字节，辅助平面字符使用代理对表示。‌‌
UTF-32‌：固定 4 字节，最简单但占用空间大

- HTML 实体编码
HTML 实体编码是用于表示在 HTML 文档中不能直接显示的字符的代码。例如，小于号（<）和大于号（>）在 HTML 中有特殊意义，用于标记 HTML 标签的开始和结束，因此直接在 HTML 文档中写这些字符会导致语法错误。为了避免这种情况，我们可以使用它们的实体编码：

< 可以用 &lt; 来表示
> 可以用 &gt; 来表示
