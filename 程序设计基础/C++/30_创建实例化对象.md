对象的内存本质
- 在 C++ 中，任何实例化的对象都必须占据内存。即使是一个完全没有任何成员的空类（Empty Class），其大小也必须至少占用 1 个字节（用于保证不同实例在内存中拥有唯一的地址）。
  
栈上创建（Stack Allocation）—— 默认首选方式
- 语法：
```cpp
Entity entity;                 // 调用默认构造函数
Entity entity("Value");       // 调用带参构造函数
Entity entity = Entity("Value"); // 同上
```
特点：- 自动生命周期（Automatic Storage Duration）：对象的寿命与所在作用域（{}）严格绑定。一旦作用域结束、栈帧弹出，编译器自动调用其析构函数并回收内存。
- 超高效率：栈内存分配本质上只是移动栈顶指针（CPU一条指令 sub rsp, ...），几乎是零开销。
- Java/C# 背景者的误区：在 Java/C# 中 Entity entity; 只是一个空的引用（null），必须配合 new 才能创建对象；但在 C++ 中，这种写法已经就地完整创建并初始化了该对象。
