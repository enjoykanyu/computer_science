### 宏定义
宏处于 C++ 编译流程的哪个阶段
源文件
→ 预处理
→ 编译
→ 汇编
→ 链接

以 # 开头的是预处理器指令：
```cpp
#include <iostream>
#define VALUE 10
#ifdef DEBUG
#endif
```
预处理阶段会先处理这些指令，再把处理后的结果交给编译器。

例如：
```cpp
#define VALUE 10
int x = VALUE;
```
预处理后近似为： int x = 10;

因此宏的本质是： 查找并替换文本
它不理解类、类型、作用域和函数语义。宏展开后，编译器才开始进行真正的语法和类型校验

### 宏与模板的区别
```cpp
#define VALUE 10       // 预处理阶段替换文本

template<typename T>  // 编译阶段处理类型和实例化
void Print(T value);
```
模板属于 C++ 语言本身，会参与类型检查；宏只是预处理器功能，所以宏可以替换的内容更加“粗暴”，甚至可以是半个表达式、花括号或完整函数

### WAIT 宏
原始代码：
```cpp
#include <iostream>

int main()
{
    std::cout << "Hello" << std::endl;
    std::cin.get();
}
```
std::cin.get() 会等待控制台输入，通常按回车后程序才继续。

定义宏
```cpp
#define WAIT std::cin.get()
```

使用它
```cpp
int main()
{
    std::cout << "Hello" << std::endl;
    WAIT;
}
```
预处理后
```cpp
int main()
{
    std::cout << "Hello" << std::endl;
    std::cin.get();
}
```


### 替换范围
宏可以替换：
- 一个数字；
- 一个表达式；
- 一条语句；
- 一部分语法；
- 一组语句

### 带参数的宏：LOG(x)
```cpp
std::cout << "Hello" << std::endl;
```

宏
```cpp
#define LOG(x) std::cout << x << std::endl
```
调用
```cpp
LOG("Hello");
```

会展开成这样
```cpp
std::cout << "Hello" << std::endl;
```
穿变量
```cpp
int value = 42;
LOG(value);
```

展开成
```cpp
std::cout << value << std::endl;
```

### 宏参数的优先级陷阱
```cpp
#define SQUARE(x) x * x
int result = SQUARE(2 + 3);
```
会展开成这样
```cpp
int result = 2 + 3 * 2 + 3;
```
由于乘法优先级更高，结果是 11，而不是 25

更安全的写法：
```cpp
template<typename T>
constexpr T Square(T value)
{
    return value * value;
}
```

```cpp
constexpr auto Square = [](auto value)
{
    return value * value;
};
```

### 宏的实际作用：Debug 与 Release
Debug 版本通常需要：
- 日志；
- 断言；
- 错误检查；
- 内存分配追踪；
- 调试辅助代码。
  Release 版本通常希望：
- 删除日志；
- 删除调试代码；
- 减少运行开销；
- 避免输出敏感信息

```cpp
#define PR_DEBUG 1
#if PR_DEBUG == 1

#define LOG(x) std::cout << x << std::endl

#else

#define LOG(x)

#endif

LOG("Hello");
```

当 PR_DEBUG == 1 时，展开为：
```cpp
std::cout << "Hello" << std::endl;
```
当 PR_DEBUG == 0 时，展开为空

此时日志代码在预处理阶段就被删除，根本不会进入编译器，也不会产生 std::cout 的运行时开销。
