### 宏定义
宏处于 C++ 编译流程的哪个阶段
源文件
→ 预处理
→ 编译
→ 汇编
→ 链接

以 # 开头的是预处理器指令：
```cpp
#include <iostream>
#define VALUE 10
#ifdef DEBUG
#endif
```
预处理阶段会先处理这些指令，再把处理后的结果交给编译器。

例如：
```cpp
#define VALUE 10
int x = VALUE;
```
预处理后近似为： int x = 10;

因此宏的本质是： 查找并替换文本
它不理解类、类型、作用域和函数语义。宏展开后，编译器才开始进行真正的语法和类型校验

### 宏与模板的区别
```cpp
#define VALUE 10       // 预处理阶段替换文本

template<typename T>  // 编译阶段处理类型和实例化
void Print(T value);
```
模板属于 C++ 语言本身，会参与类型检查；宏只是预处理器功能，所以宏可以替换的内容更加“粗暴”，甚至可以是半个表达式、花括号或完整函数

### WAIT 宏
原始代码：
```cpp
#include <iostream>

int main()
{
    std::cout << "Hello" << std::endl;
    std::cin.get();
}
```
std::cin.get() 会等待控制台输入，通常按回车后程序才继续。

定义宏
```cpp
#define WAIT std::cin.get()
```

使用它
```cpp
int main()
{
    std::cout << "Hello" << std::endl;
    WAIT;
}
```
预处理后
```cpp
int main()
{
    std::cout << "Hello" << std::endl;
    std::cin.get();
}
```


### 替换范围
宏可以替换：
- 一个数字；
- 一个表达式；
- 一条语句；
- 一部分语法；
- 一组语句
