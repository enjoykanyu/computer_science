误解：很多人以为“栈（Stack）”是存放在 CPU 高速缓存或某种特殊的高速硬件里的，而“堆（Heap）”才是物理内存。

栈和堆在物理世界上完全没有区别！它们都位于计算机同一个物理内存（RAM）芯片中

操作系统视角的内存分配：
程序启动时，操作系统加载器（OS Loader）将二进制加载进虚拟地址空间，并为其划分了不同的虚拟内存段。- 栈（Stack）：通常是一块预设固定大小的连续内存（在 Windows 上默认通常是 1 MB ~ 2 MB；Linux 默认通常是 8 MB）。
- 堆（Heap）：同样拥有初始大小，但随着程序调用 new/malloc，它可以向操作系统动态申请扩张，容量几乎只受限于物理内存和虚拟地址空间上限

### C++的标准
C++ 官方标准中并没有直接出现“栈（Stack）”这个物理词汇，而是定义为：- 自动存储期（Automatic Storage Duration）：局部对象随作用域进入而创建，退出而销毁（底层由栈实现）；
- 动态存储期（Dynamic Storage Duration）：通过 new/delete 按需申请和释放的自由存储区（Free Store / Heap）

栈溢出（Stack Overflow）的本质：
正因为栈空间非常有限（仅 1~2 MB），如果你在栈上分配超大对象（如 int arr[1000000];）或发生无限递归，栈指针一瞬间就会越过预设的保护页（Guard Page），触发操作系统的内存访问违规异常（Crash: Stack Overflow）
### 三种数据在栈与堆的分配对比

```cpp
#include <iostream>

struct Vector3 {
    float x, y, z;
    Vector3() : x(10), y(11), z(12) {}
};

int main() {
    // 1. 标量类型（int）
    int value = 5;                  // 栈分配
    int* hValue = new int;          // 堆分配
    *hValue = 5;

    // 2. 数组类型（int array）
    int array[5];                   // 栈分配
    array[0] = 1; array[1] = 2; array[2] = 3; array[3] = 4; array[4] = 5;

    int* hArray = new int[5];       // 堆分配
    hArray[0] = 1; hArray[1] = 2; hArray[2] = 3; hArray[3] = 4; hArray[4] = 5;

    // 3. 复合对象（Struct / Class）
    Vector3 vector;                 // 栈分配
    Vector3* hVector = new Vector3(); // 堆分配

    // 堆内存必须手动释放！
    delete hValue;
    delete[] hArray;
    delete hVector;
}
```


### 栈的紧密相邻对比堆的随机碎片
栈内存排布：整齐划一、紧密相邻
栈的方向（向下生长）：value 处于较高内存地址，后声明的 array 处于较低内存地址。Cherno 指出：在 x86/x64 架构下，栈是向低地址方向（反向）生长的

堆内存排布：离散分布
堆内存由操作系统的堆管理器分配，哪里的空闲块合适就塞在哪里，两者在物理地址上彼此远离、完全离散
