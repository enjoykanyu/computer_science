什么是三目运算符（Conditional / Ternary Operator）
- 它是 C++ 中唯一拥有三个操作数的运算符：
  condition ? expression if_true : expression if_false
    - 本质与意图：它不仅是 if-else 的“语法糖”，更重要的是它是表达式（Expression）而非语句（Statement）。
    - if-else 是语句，不能直接放在赋值符号右侧；
    - 条件运算符产生一个计算结果，专门用于条件初始化与条件赋值（如 int speed = level > 5 ? 10 : 5;）。

核心优势 1：代码可读性与意图表达
- 将 4~6 行的分支赋值语句精炼为 1 行；
- 明确传达“代码的核心动作是给该变量赋值，只是取值取决于条件”，让数据流向一目了然。

核心优势 2：性能与对象生命周期（关键重难点）
- 传统 if-else 分支赋值：

```cpp
std::string rank; // 1. 先调用默认构造函数生成空字符串
if (level > 10)
    rank = "Master"; // 2. 构造临时对象，再调用拷贝/移动赋值运算符覆盖
else
    rank = "Beginner";
```

- 使用三目运算符：

```cpp
std::string rank = level > 10 ? "Master" : "Beginner";
// 直接调用对应构造函数就地初始化目标对象（配合编译器 RVO / 复制消除），省去了默认构造和覆盖赋值的开销。
```

- 支持 const 变量初始化：如果想让 rank 是 const 常量，用普通 if-else 根本无法实现（因为先声明再赋值违反 const 规则），而三目运算符允许在定义时直接赋予带有条件的初始值。
