### 引入
语言对比：在 Python 等动态语言中，你可以极其随意地写 return a, b（底层自动打包为元组）；
但在 C++ 这种强类型静态语言中，传统函数签名在语法上只允许声明一个明确的返回类型。

真实工程背景（OpenGL 案例）：
我们需要编写一个解析着色器文本文件的函数 ParseShader(filepath)，这个函数必须同时向外吐出两个独立的字符串：
1. VertexShaderSource（顶点着色器源码）
2. FragmentShaderSource（片段着色器源码）

核心设问：如何优雅、高效且无歧义地把这两个（甚至更多不同类型的）数据带回给调用者

### 方案一：输出形参（Pass-by-Reference / Pointer 出参）
Cherno 演示的第一种思路，是完全不依赖任何复杂包装类的传统 C/C++ 方案——通过函数参数往外带数据。
1. 引用传递（Pass by Reference）出参
```cpp
void ParseShader(const std::string& filepath, std::string& vertexSource, std::string& fragmentSource) {
    // 假设内部解析得到了 vs 和 fs
    vertexSource = vs;
    fragmentSource = fs;
}

int main() {
    std::string vs, fs;
    ParseShader("res/shaders/Basic.shader", vs, fs);
    CreateShader(vs, fs);
}
```
字符串是在调用方 main 的栈帧上提前创建的，传进去的是指针地址，函数内部直接就地赋值写入那块内存。
缺点：不能写在一行中，调用前必须先声明两个空变量，代码显得略微啰嗦
