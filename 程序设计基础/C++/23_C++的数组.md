### 原生数组
数组本质上就是一组元素的集合
```cpp
#include <iostream>

class Entity{
public:

};
int main()
{   
    int testArray[5];
    int* ptr = testArray;
    for (int i = 0; i < 5; i++)
    {
        /* code */
        testArray[i] = 2;
    }    
    testArray[2] = 5;
    *(ptr+2)  = 2;
    std::cin.get();
}
```
