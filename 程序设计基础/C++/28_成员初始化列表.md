成员初始化列表（Member Initializer List）
- 语法形式：在构造函数参数列表后使用冒号 :，多个成员之间用逗号 , 分隔
```cpp
Entity() : m_Name("Unknown"), m_Score(0) {}
```
在对象成员构造分配内存的同时进行直接初始化，而不是先构造再赋值

必须使用初始化列表的场景（强制语义，非单纯优化）
在以下三种情况下，无法在函数体内赋值，必须使用成员初始化列表（或类内成员就地初始化）：
- const 成员变量：只读常量一旦生成不可被修改赋值。
- 引用类型成员（Type&）：引用必须在定义/构造时绑定对象，不能重绑定。
- 没有默认构造函数的类类型成员：如果不放在初始化列表中显式调用其有参构造，编译器在进入函数体前无法自动生成默认构造调用，会直接报编译错误。

C++11 类内就地初始化（Default Member Initializer）的交互
- C++11 支持在类声明时直接给默认值：int m_Score = 0;。
- 规则：如果成员在初始化列表中显式给出了初始值，以初始化列表为准；如果列表中未显式提供，才会回退到类内默认初始值。
