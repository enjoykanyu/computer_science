运算符：本质上是一种特定的符号（Symbol），用于替代普通函数调用来执行某种操作。
丰富的运算符族谱：除了常见的数学运算（+, -, *, /）外，C++ 中大量符号都是运算符：- 指针与内存：解引用 *、成员访问箭头 ->、取地址 &、复合赋值 +=；
- 流操作：向控制台输出的左移/流插入运算符 <<；
- 内存分配关键字：new 和 delete 本质也是运算符；
- 特殊符号：逗号运算符,、函数调用运算符 ()

重载：赋予现有运算符全新的语义、支持新的自定义类型参数。
语言对比与设计哲学：
- Java 完全不支持运算符重载；C# 仅支持经过严格限制的部分运算符；而 C++ 赋予了开发者100% 的绝对掌控权。
- 核心准则（克制与直觉）：运算符本质就是函数。与其叫 Add，不如用 +；但切忌滥用！如果一个运算符的行为违反自然直觉（比如某些库用 & 表示数据序列化 push），别人必须跳转查看实现才能看懂，那就是彻头彻尾的糟糕设计。


## 引入运算符重载
```cpp
struct Vector2
{
    float x, y;

    Vector2(float x, float y)
        : x(x), y(y) {}
};
```
像这样定义一个向量结构体

有一个位置向量 position 和一个速度向量 speed：
```cpp
Vector2 position(4.0f, 4.0f);
Vector2 speed(0.5f, 1.5f);
```
若计算向量相加，在Java语言中得增加一个Add函数
```cpp
struct Vector2
{
    float x, y;

    Vector2(float x, float y)
        : x(x), y(y) {}

    // 返回新对象，const 引用避免拷贝，const 成员函数保证不改变自身
    Vector2 Add(const Vector2& other) const
    {
        return Vector2(x + other.x, y + other.y);
    }
};
```
main函数中调用
```cpp
Vector2 result1 = position.Add(speed);
```
此时加入一个速度加成系数 powerup（例如吃到道具速度增加 1.1 倍）：
为了支持相乘，我们又得照猫画虎写一个 Multiply 函数：
```cpp
Vector2 Multiply(const Vector2& other) const
{
return Vector2(x * other.x, y * other.y);
}
```
此时要计算最终位置，代码变成了：
```cpp
Vector2 powerup(1.1f, 1.1f);
Vector2 result2 = position.Add(speed.Multiply(powerup));
```
很难读

- 改造为运算符重载
```cpp
struct Vector2
{
    float x, y;

    Vector2(float x, float y)
        : x(x), y(y) {}

    Vector2 Add(const Vector2& other) const
    {
        return Vector2(x + other.x, y + other.y);
    }

    // 重载 + 运算符：可以复用已有的 Add 方法
    Vector2 operator+(const Vector2& other) const
    {
        return Add(other);
    }
};
```
完善乘法运算符 operator*
```cpp
Vector2 Multiply(const Vector2& other) const
{
    return Vector2(x * other.x, y * other.y);
}

Vector2 operator*(const Vector2& other) const
{
    return Multiply(other);
}
```
在 main 函数中，原本丑陋的嵌套调用直接变成了极度清爽的数学表达式：
```cpp
Vector2 result = position + speed * powerup;
```
对比之前的写法
```cpp
// 没有重载，全部用 Add, Multiply
Vector2 newPos = position.Add(speed.Multiply(dt))
                         .Add(acceleration.Multiply(0.5f).Multiply(dt * dt));
```
简洁多了

注意实际项目中这样写就完事了，不需要多余的 Add 函数
```cpp
Vector2 operator+(const Vector2& other) const {
return Vector2(x + other.x, y + other.y);
}
```

### this关键字
this关键字指向了当前的对象
```cpp
Vector2 Add(const Vector2& other) const
{
    return *this + other; // this 是指向自身的指针，*this 即解引用为 Vector2 对象本身
}
```
注意若调用对象的内部函数得解引用(*this).函数 还可以 this->函数


### 重载流插入运算符 <<
若咱想打印对象 std::cout << result << std::endl; 这样打印会报错

因为标准库目前只认识 std::cout << float 或 std::cout << int，并不认识 Vector2。
- 重载<<函数解决打印对象问题
```cpp
std::ostream& operator<<(std::ostream& stream, const Vector2& other)
{
    stream << other.x << ", " << other.y;
    return stream; // 关键：务必返回 ostream 引用！
}
```
这里和Java的对于tostring重写方法差不多
- 形参1：std::ostream& stream（不能传值，因为流对象禁止拷贝，必须传引用）。
- 形参2：const Vector2& other（常量引用传参，避免多余拷贝）。
- 返回值：std::ostream&。之所以返回 stream 自身的引用，是为了支持链式调用！
    - 表达式 std::cout << result << std::endl; 从左向右结合为 (std::cout << result) << std::endl;。
    - 第一步执行完返回了 std::cout 本身，才能继续传递给下一个 << std::endl。
    
### 关系运算符==与!=
Java中比较两个自定义对象不能写==（否则比较的是引用地址），必须写.equals()，在C++中我们可以直接重载==
- 重载 operator==
```cpp
bool operator==(const Vector2& other) const
{
    return x == other.x && y == other.y;
}
```
- 重载 operator!=
```cpp
bool operator!=(const Vector2& other) const
{
    return !(*this == other); // 解引用 this 得到当前对象，调用 ==，然后整体取反
}
```
