new 的核心目的与底层过程
- 核心目的：在**堆（Heap / Free Store）**上分配所需字节大小的连续内存，并返回指向该内存地址的指针。
- 底层工作流：
    1. 计算大小：根据类型计算所需的内存字节数（例如 new int 为 4 字节，new Entity 为 sizeof(Entity)）。
    2. 寻找空闲空间：向操作系统/运行时库申请连续内存。运行时底层通过**空闲链表（Free List）**等内存分配器机制查找满足大小的连续内存块（具有一定时间开销）。
    3. 返回指针：成功后返回首地址指针。

基本语法与使用形式
- 标量/单一对象：
```cpp
int* b = new int;               // 堆上分配 4 字节
Entity* e = new Entity();       // 堆上分配 Entity，并调用默认构造函数
```

- 数组分配：
```cpp
int* arr = new int[50];         // 分配 50 * 4 = 200 字节连续内存
Entity* eArr = new Entity[50];  // 分配连续内存，并依次调用 50 次默认构造函数
```

### new 与 malloc 的根本区别（核心概念）
- new 本质上是一个运算符（Operator），底层通常调用 operator new 函数（其默认实现往往基于 C 标准库的 malloc）。
- 关键差异：
  - malloc(sizeof(Entity))：纯粹在堆上划出一块未初始化的原始内存（返回 void*），绝对不会调用构造函数。
  - new Entity()：不仅分配内存，还会显式触发对象的构造函数完成对象初始化，且具备类型安全性（直接返回强类型的 Entity*，无需像 C 那样强转）
